# 🎬 Netflix Movies & TV Shows — SQL Data Analysis

![Netflix Logo](https://github.com/SnehaDinodia027/Netflix_sql_projecg/blob/main/Netflix-Logo.png)

## 📌 About the Project

This project is a **SQL-based data analysis of Netflix Movies and TV Shows** using PostgreSQL.

The analysis focuses on **50 real-world business questions** covering content types, ratings, genres, countries, release trends, directors, actors, movie duration, TV show seasons, and Indian content.

The goal is to demonstrate practical **SQL and data analysis skills** using a real-world dataset.

## 📊 Analysis Performed

The project answers **50 SQL business questions**, including:

* Movies vs TV Shows distribution
* Most common ratings
* Year-wise content releases
* Top content-producing countries
* Longest and shortest movies
* TV shows by number of seasons
* Popular genres
* Director analysis
* Actor analysis
* Indian content analysis
* Movie duration analysis
* Rating-wise content distribution
* Recently added content
* Content classification using text analysis

All SQL queries are available in:

```text
netflix_analysis.sql
```

## 🚀 How to Run

1. Install PostgreSQL and pgAdmin 4.
2. Create a database.
3. Create the `netflix` table.
4. Import the Netflix dataset.
5. Open `netflix_analysis.sql`.
6. Run the queries in PostgreSQL.
